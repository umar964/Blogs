# AI-Powered Blogs Website  

This is a blog management website where admins can create, update, and delete blogs. It also supports AI-powered blog generation. The admin can provide a title, and the AI will generate a complete blog. 

## Features
- Admin authentication (login/logout)  
- Manually create, update, and delete blogs  
- Automatically generate blogs using AI by entering a title  
- Blogs stored and managed in a database
